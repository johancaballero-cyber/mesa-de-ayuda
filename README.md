# Sistema de Mesa de Ayuda

## Descripción del proyecto

Este proyecto consiste en desarrollar un sistema de mesa de ayuda para registrar y dar seguimiento a solicitudes de soporte técnico.

Su objetivo es organizar los problemas reportados por los usuarios y facilitar el trabajo del encargado de soporte.

El sistema permitirá registrar tickets, consultar sus detalles y cambiar su estado a Pendiente, En proceso o Resuelto.
